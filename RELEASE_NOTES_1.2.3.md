The machine will now refuse a firmware update while turns are held in a string.

Installing an update frees both heads, and any twist stored in the string
unwinds the moment they let go — quietly, with nothing on the machine able to
count what was lost. Until now the update went ahead anyway. If you press
Firmware Update and it refuses, that is this fix working: untwist to zero,
press FREE HEADS on the Twist page, then update.

A cycle stretch now records how it ended.

The reason it stopped, the cycle it stopped on, and the numbers behind the
result are kept after the run finishes. Before, they were wiped the moment
anyone started the next run, so a completed run left nothing behind saying
whether the string had settled or simply run out of cycles.

The downloaded cycle log now carries its own settings on the first line —
tension band, cycle time, cycle count, and the thresholds the result was judged
against — and the result itself on the last line. A log can be read months
later without having to remember what it was run at.

⚠ One cycle log is one run. Starting a new cycle stretch replaces the previous
log, so download it before you start the next one.

Your calibration, WiFi settings and saved run logs are kept.
