Power Serve — USB Flasher

One-time install of the firmware that adds the Firmware Update button. After this, updates are done from the machine's own Setup page — no cable, no computer.

Before you plug anything in

  • Take the string off the machine and leave it off. The board reboots during this and the tension axis is released.
  • Motor and driver power OFF. USB alone powers the controller board.
  • Do not close this tab or unplug the cable while it is writing.

What you need

BrowserChrome or Edge on a desktop or laptop. Safari, Firefox, iPad and Android phones cannot do this — they have no Web Serial support.
CableUSB cable from the laptop to the controller board. A charge-only cable will not work — it must carry data.
TimeAbout two minutes.

Install

This browser cannot talk to the board. Open this page in Chrome or Edge on a laptop. This page must be opened over https:// to use the serial port.
  1. Click Connect & Install.
  2. Pick the serial port in the browser's dialog. On Windows it is usually COM3–COM9, described as Silicon Labs or CP210x. If no port is listed, the cable is charge-only or the driver is missing.
  3. Choose Install and wait. Do not touch the cable.
  4. When it finishes, the board reboots on its own.

If the board will not enter flashing mode

Hold the BOOT button down, tap EN (or RST), then release BOOT, and click Install again. Some boards need this; most do not.

After it reboots

  1. Open http://PS3000.local/ on the tablet.
  2. Tap the ⚙ cog in the top strip.
  3. Scroll to FIRMWARE. It should show the version you just installed.

Your load-cell calibration, WiFi credentials and stored run logs are all kept — this writes the program only, not the settings.

This page is also the way back

If an update ever leaves the machine unable to start, bookmark this page and come back to it. Plugging in the USB cable and re-flashing from here recovers the machine from any bad firmware. It is the reason the USB path stays available.
